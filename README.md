# 🐤 Flappy Bird Game (Python)

A smooth and responsive Flappy Bird clone built using Pygame. This project features simple physics, dynamic pipe generation, real-time collision detection, and a persistent high score system. Perfect for beginners to explore game development and event-driven programming in Python.

---

## 🚀 Features

- 🎮 Classic Flappy Bird gameplay  
- 🐤 Smooth bird physics and movement  
- 🌿 Infinite pipe generation  
- 💥 Collision detection system  
- 🏆 High score saving using file system  
- 🖥️ Clean and simple UI  
- ⚡ Lightweight and fast  
- ⌨️ Press SPACE to play / jump  

---

## ⚙️ How It Works

1. Bird falls due to gravity  
2. Press SPACE to make the bird jump  
3. Pipes move continuously from right to left  
4. Avoid hitting pipes or screen boundaries  
5. Score increases when passing pipes  
6. High score is saved in a file
